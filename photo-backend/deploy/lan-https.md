# Локальный HTTPS-доступ к админке

Адрес: `https://192.168.3.108:8443/admin`. Прокси слушает только домашний IPv4-адрес Orange Pi и принимает запросы только от `192.168.3.0/24`. Он проверяет Host и Origin, передаёт админку на loopback 8788, а noVNC на loopback 6080 только после проверки действующей административной cookie. WebSocket проходит через тот же HTTPS-адрес. Порт VNC 5900 остаётся только на loopback. К cookie, выданной через HTTPS, прокси добавляет `Secure`.

`lan-https.mjs` не запускается без файла сертификата и закрытого ключа. Ключ сервера хранится только вне Git в `/home/admin/clevervet-runtime/lan-tls` с правами 0600. Ключ CA удалён после выпуска сертификата; для продления через год потребуется новый CA и повторная установка доверия на устройствах. Сертификат сервера содержит SAN `IP:192.168.3.108` и `extendedKeyUsage=serverAuth`. Проверить сертификат: `openssl verify -CAfile lan-tls/ca.crt -verify_ip 192.168.3.108 lan-tls/server.crt`. При смене IP создать новый сертификат и обновить адрес в скрипте запуска.

На iPhone передать профиль `clevervet-local-ca.mobileconfig`, содержащий **только публичный сертификат CA**. Открыть его в Files, установить через «Настройки → Профиль загружен», затем включить доверие в «Настройки → Основные → Об этом устройстве → Доверие сертификатам». Сверить SHA-256 отпечаток CA с отпечатком, переданным отдельно по доверенному каналу. После этого открыть адрес выше в Safari без обхода предупреждений TLS. Входить существующим паролем, запустить Chromium, нажать «Открыть окно Chromium», получить временный VNC-пароль через ссылку панели. На телефоне для ввода текста открыть боковую панель noVNC и нажать значок клавиатуры, затем коснуться нужного поля в Chromium. После работы закрыть Chromium и выйти из админки.

Резервный доступ через SSH остаётся: `ssh -L 8788:127.0.0.1:8788 -L 6080:127.0.0.1:6080 orangepi`, затем `http://127.0.0.1:8788/admin`. Оригинальный OIDC callback остаётся `http://localhost:8788/admin/oidc/callback` и не считается рабочим без зарегистрированного клиента Auth0.

Для автозапуска скопировать `start-local.sh` и `lan-https.mjs` в соответствующий каталог `/home/admin/clevervet-runtime/photo-backend/deploy`, выдать скрипту запуска право на выполнение и добавить в crontab пользователя `admin` строку `@reboot /home/admin/clevervet-runtime/photo-backend/deploy/start-local.sh`. Это не меняет VPN, маршрутизацию, firewall или настройки Wi-Fi. Проверить после запуска `/health`, 401 без cookie на `/admin/status`, 403 без cookie на `/admin/vnc/vnc.html`, TLS с CA и состояние VPN-шлюза.
