# CleverVet photo backend — восстановленная основа

Исходный локальный коммит `f50c68d` пока недоступен. Этот каталог создан заново в отдельной ветке и **не является точной копией** прежнего прототипа.

Сейчас HTTP-процесс слушает только `127.0.0.1:8787` и отдаёт `GET /health`. Ни один HTTP endpoint не выполняет реальную запись. Модуль `src/service.ts` содержит изолированную цепочку S3 → свежий GET пациента → условный PUT → контрольный GET, инъекции для mock-тестов, ограничение пилотным пациентом и защиту от повторных запросов. При отсутствии ETag условный PUT запрещён.

```sh
npm ci
npm test
npm start
```

Для продолжения требуются: подтверждение точного контракта CleverVet API и поддержки `If-Match`, OIDC авторизация серверной сессии, проверка JWT и пользовательских прав, защищённый HTTP endpoint загрузки, админка и туннель. `PHOTO_WRITES_ENABLED` следует оставить `false` до отдельного разрешённого пилота.
