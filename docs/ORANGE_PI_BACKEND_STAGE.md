## Локальный доступ и управление

На компьютере администратора открыть SSH-туннель:

```sh
ssh -L 8788:127.0.0.1:8788 -L 6080:127.0.0.1:6080 orangepi
```

Адрес панели: `http://127.0.0.1:8788/admin`. После входа кнопка запускает Chromium. Окно браузера откроется через ссылку панели на локальном порту 6080. Случайный VNC-пароль доступен только пользователю `admin` Orange Pi в `/dev/shm/clevervet-vnc-password` во время работы браузера. Пароль CleverVet и MFA вводить непосредственно в этом браузере.

Временные процессы запускаются непривилегированным пользователем. Для остановки админки найти PID по `ss -lntp | grep 8788` и отправить ему `SIGTERM`; обработчик закроет Chromium. Для backend аналогично проверить порт 8787. Системные службы, маршруты и правила VPN при этом не менять.

## Проверки и ограничения

Backend-тесты проверяют JWT, HTTP, ограничения JPEG и размера, повтор запроса, лимит частоты, mock S3/API и конфликт `If-Match`. Сквозной тест Test3 проверяет диалог, HTTP, mock S3, mock PUT и повторный GET. Полный набор frontend-тестов запускается в полной копии дерева на Orange Pi. Ни один тест не использует реальные данные пациентов.

Перед реальной загрузкой нужны домен и именованный Cloudflare Tunnel, проверенный разрешённый OIDC-процесс, независимая авторизация пользователя Test3, подтверждённые права S3 и `If-Match` CleverVet, отдельный тестовый пациент и явное разрешение на пилот. Опубликованный Test3 пока не отправляет фотографию в этот backend.
